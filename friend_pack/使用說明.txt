=========================================================
帕魯不打烊 · 朋友端 MOD 安裝工具 v1.0.9
=========================================================


▌這包是什麼？

這是「帕魯不打烊」伺服器管理員幫你打包好的 MOD 安裝小工具。
雙擊 PalworldFriendModInstaller.exe 就能開啟。

▌怎麼用？

1. 對「PalworldFriendModInstaller-v1.0.9.zip」按右鍵
   →「解壓縮到目前資料夾」或「解壓縮到 PalworldFriendModInstaller-v1.0.9\」

2. 打開解壓出來的資料夾，雙擊「PalworldFriendModInstaller.exe」

3. 第一次開可能會跳兩個警訊，照下面做就好（這是 Windows 對沒簽章的
   小工具的標準警訊，不是真的有病毒）：

   ┌──────────────────────────────────────────────────┐
   │ (A) Windows SmartScreen 警訊                       │
   │     訊息：「Windows 已保護您的電腦」                 │
   │     解法：點「其他資訊」→ 跳出藍色連結               │
   │           「仍要執行」→ 點下去就會開                 │
   │                                                    │
   │ (B) Windows Defender / 防毒軟體把檔案隔離           │
   │     解法：「Windows 安全性」→「病毒與威脅防護」     │
   │           →「保護紀錄」→ 找到 PalworldFriendMod     │
   │           →「允許在裝置上執行」                      │
   └──────────────────────────────────────────────────┘

4. 工具開啟後，按「🚀 一鍵安裝 UE4SS」（如果還沒裝過）

5. 點「同步 MOD 資料庫」→ 會看到「極致天氣」+「帕魯繁殖助手」兩個 MOD

6. 點 MOD 卡上的「📥 安裝」就會自動下載並安裝到你的 Palworld


▌安裝前請先關閉 Palworld

裝 / 卸 MOD 時 Palworld 不能在跑（會鎖住檔案）。
建議流程：關 Palworld → 開工具裝 MOD → 重新開 Palworld。


▌現在能裝的 MOD

• 帕魯繁殖助手 (BreedingHelper) — 計算配種結果、染色 / IV 鎖定
• 極致天氣 (UltraWeather) — 自訂日出日落、體積雲、光線更戲劇化


▌給朋友

這個工具是「帕魯不打烊」伺服器專用的 MOD 安裝小幫手，
不是官方工具。有問題找伺服器管理員或在 Discord 跟我們說。


▌檔案驗證

本包附 SHA256.txt，可以用 certutil 驗證：

  certutil -hashfile PalworldFriendModInstaller.exe SHA256

比對 SHA256.txt 裡的字串確認檔案沒被篡改。


▌更新

工具會在開啟時自動從 GitHub 拉最新的 MOD 清單，
不需重抓這個 zip。但如果「帕魯不打烊」工具本身有更新，
會另外公告，再重新下載這個 zip 即可。
